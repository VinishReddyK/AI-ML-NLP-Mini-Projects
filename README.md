# AI, ML, and NLP Mini Projects  

Welcome to my repository of AI, Machine Learning (ML), and Natural Language Processing (NLP) mini projects! This collection represents the knowledge and skills I have gained throughout my master's program. Over time, I worked on various topics, exploring a mix of theoretical concepts and practical implementations.  

## 🛠️ What's Inside?  

This repository includes Jupyter notebooks that cover:  
- **Data Preprocessing**: Techniques to clean, transform, and prepare data for modeling.  
- **Machine Learning**: Supervised and unsupervised algorithms, from linear regression to clustering.  
- **Deep Learning**: Neural networks, model optimization, and frameworks like TensorFlow and PyTorch.  
- **NLP**: Text preprocessing, sentiment analysis, named entity recognition, and text summarization.  
- **Other Topics**: Miscellaneous experiments and tools that piqued my curiosity during my learning journey.  

## ⚠️ Note on Datasets  

While each notebook is self-contained, the datasets used for these projects are not included in this repository. Over time, some datasets were lost, and only the notebooks remain. If you’d like to run a specific project, you may need to provide similar datasets or adapt the code to work with available data.
